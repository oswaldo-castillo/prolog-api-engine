# Motor de Inferencia Lógica como Servicio

Este proyecto es una API REST que expone un motor de razonamiento simbólico (Prolog) utilizando Node.js.

## Requisitos

- Node.js (v14 o superior)
- npm

## Instalación

1. Descarga el código o clona el repositorio.
2. Abre una terminal en la carpeta raíz.
3. Ejecuta el comando:

   ```bash
   npm install
